📱 SnapEats
SnapEats é uma aplicação web desenvolvida com o objetivo de conectar usuários a restaurantes por meio de avaliações reais de pratos e estabelecimentos. Mais do que uma simples plataforma de reviews, o SnapEats oferece insights inteligentes para que restaurantes possam melhorar seus serviços com base em feedbacks construtivos.

🔍 Principais Funcionalidades:
Cadastro e autenticação de usuários (clientes e estabelecimentos)
Avaliação de restaurantes e pratos com notas e comentários
Respostas públicas dos estabelecimentos às avaliações
Sistema de filtro por palavra-chave, nota, prato e data
Visualização de gráficos com médias de avaliação
Recomendações de restaurantes com base em preferências e localização
Dashboard analítico para estabelecimentos
Sistema de denúncia e notificações

🎯 Objetivo:
Transformar a experiência gastronômica em algo mais confiável, personalizado e colaborativo, promovendo melhorias reais no setor de alimentação.

🛠️ Tecnologias Utilizadas:
Backend: Python (Flask ou FastAPI)

Frontend: Angular

Banco de Dados: MYSQL

Autenticação: JWT

API RESTful
